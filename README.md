# TaskEase ✅

Simple Task Management Web App — Capstone-ready project.

## What is it?
TaskEase is a minimal task manager that lets you add, complete, and delete tasks. Tasks persist in the browser using `localStorage`.

## Features
- Add a task (press Enter or click Add)
- Mark a task as completed
- Delete a task
- Clear completed tasks or clear all
- Tasks persist in the browser

## Tech
- Plain HTML, CSS, JavaScript
- No build tools required

## How to run
1. Clone or download the repository.
2. Open `index.html` in your browser (double-click or right-click -> Open with...).
3. Use the app and record demo.
